Este é um repositório para versionamento do código da aplicação desenvolvida na matéria de Desenvolvimento de Projetos Computacionais ll, desenvolvido no primeiro semestre de 2025 no curso de Sistemas de Informação.

## Sobre o Projeto

Vakantes é uma aplicação desenvolvida em Java utilizando Spring Boot e Thymeleaf, com integração ao banco de dados PostgreSQL. O sistema tem como objetivo gerenciar vagas e candidatos, facilitando o processo de seleção e administração de oportunidades de emprego.

## Tecnologias Utilizadas

- Java 17
- Spring Boot 3
- Thymeleaf & Spring Security
- PostgreSQL
- Apache Maven
- JavaScript
